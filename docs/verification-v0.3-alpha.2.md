# v0.3.0-alpha.2 验证报告

日期：2026-11-06；目标：普通 Forerunner 255；SDK 9.3.0 / Java 17；渭南 z15、121 张底图。

## 问题与修复

用户反馈 alpha.1 功能基本正常，但记录较长轨迹后平移更卡。旧版每次刷新都会重复投影相邻端点，并为每条线段调用四次 drawLine，屏幕外线段也进入绘制。

本版在点追加/恢复时缓存世界坐标；缓存与原轨迹共用 800 条环形上限。刷新时只读取缓存，对同一屏幕边界之外的线段提前跳过，穿过屏幕的线段仍保留；一次 2 像素画笔代替四次画线，结束后恢复 1 像素画笔。FIT、距离、定位采样、地图瓦片和恢复存储格式没有改动。

画笔接口 [Dc.setPenWidth](https://developer.garmin.com/connect-iq/api-docs/Toybox/Graphics/Dc.html#setPenWidth-instance_function) 自 API 1.0 可用；已在 FR255 模拟器完成实际地图绘制，未提高最低 API 要求。

## 同输入性能对照

旧版生产代码来自 `267cf550b7bfc46b959bf793ce7881d75966492a`，仅加入与新版相同的 `PanBenchmark.mc`。两边使用相同地图资源、SDK、设备配置和主机，分别运行单项基准，测量时未并行执行构建。

每场景预热一次，然后水平移动 20 帧（前 10 帧每次 +40 px，后 10 帧每次 -40 px），在 260×260 BufferedBitmap 上测量完整 `MapView.onUpdate`。dense800 为 20 个近邻纬度反复组成的 800 点，spread800 为向北展开的 800 点；这两组是可重复的合成输入，并非用户活动。平移时轨迹会进入/离开屏幕。日志在计时结束后输出。P95 为 20 个样本中第 19 小值。

| 场景 | 旧版中位数 / P95 / 最大值 | 新版中位数 / P95 / 最大值 | 绘制后内存最大采样（旧 → 新） |
|---|---|---|---|
| 空轨迹 | 15 / 16 / 31 ms | 7.5 / 16 / 16 ms | 54,976 → 67,352 B |
| 密集 800 点 | 63 / 78 / 79 ms | 16 / 31 / 31 ms | 89,112 → 137,744 B |
| 展开 800 点 | 63 / 78 / 78 ms | 16 / 31 / 31 ms | 89,120 → 137,752 B |

原始数据见安装包的 `pan-before.log`、`pan-after.log` 和 `pan-comparison.json`。主机计时呈约 15～16 ms 的粗颗粒，包含 0 ms 样本；表中 7.5 ms 是样本中位数计算结果，不代表亚毫秒测量精度。结果只说明此测试中重复计算与绘制成本降低，不能推导实机帧率、按键到显示延迟或续航。

## 回归与内存

- **38 项 Monkey C 测试逐项 PASS，摘要 passed=38、failed=0、errors=0。** 包含基准、原有记录/定位/菜单/真实 Storage 与原生 FIT 调用测试，以及 5 项绘制回归。
- 正式包及测试包均编译成功；4 项 Python 离线构建工具测试通过。首次本地 Python 运行因系统临时目录写入被拒而失败，改用工作区内临时目录后原测试全部通过，未修改测试逻辑。
- 新增回归覆盖：重复平移不重新投影；超过容量后原坐标和缓存仍对应；清空/恢复/断段正确；四侧屏幕外线段剔除；两端在外但穿过屏幕的线段保留；画笔复位与边缘粗线。
- 满容量完整地图绘制测试采样 **137,496 B**；800 点双槽存储/恢复测试采样 **219,304 B**。各采样低于项目 350 KiB 目标，但不代表持续峰值或实机占用。空间换取速度的新增缓存保持有界。
- 同一组测试包含真实 FR255 图形接口和原生活动开始/暂停/继续/保存调用；并未新增完整 FIT 文件解析或 Connect 同步证据。

运行器仍返回退出码 1，与逐项 PASS 和成功摘要不一致；这是已有的 SDK 运行器异常，保留原始日志和退出码。构建启用警告输出，动态数组类型推断警告仍存在，不能称为零警告构建。正式 PRG 与测试 PRG 分开构建，安装包只提供正式 PRG。

## 实机待验

更新后先用同一条已保存长轨迹连续平移，检查停顿、回中、菜单与断段，再在下一次长记录后重试。步骤见 [INSTALL-V03.md](INSTALL-V03.md)。新版本仍为 alpha；2 小时稳定性、实际内存/电量、完整 FIT 内容和 Connect 同步未在本次自动验证中完成。

源提交、正式 PRG 的大小/哈希、构建警告数及对应 CI 结果记录于安装包 `build-info.json`；旧 alpha.1 包保留用于回退。
