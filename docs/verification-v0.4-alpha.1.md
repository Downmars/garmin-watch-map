# v0.4.0-alpha.1 构建与验证

日期：2026-11-06。目标为普通 Forerunner 255，Connect IQ SDK 9.3.0、Java 17.0.20.1，最低 API 保持 3.0。基于 v0.3.0-alpha.3 的已验收功能继续开发，使用 `iteration/v0.4-browsing` 分支；v0.3 原安装包保留用于回退。

## 本次交付

- 渭南 z15 街道 / z13 概览两级离线底图，133 张合成图片，屏幕横向视野约相差 4 倍；覆盖承诺仍为原有约 22.2 km 方形区域。
- START 循环上下、左右、缩放；缩放模式 UP 放大、DOWN 缩小。缩放保持地理中心与浏览/跟随状态，比例尺随级别和纬度变化。
- 可见瓦片直接索引，最多保留 4 个资源编号，每次定时器启用一个新编号；图片在绘图回调内解析，交由系统缓存。这不是每帧最多一次解码的保证。
- 800 条轨迹及投影采用连续数组，渲染直接读取坐标，保留原断段、环形覆盖、FIT 生命周期、分批启动恢复和 v1 双槽存储格式。
- 最近轨迹自动概览、地图信息页、多次活动列表和路线导航尚未实现。

## 验证结果

| 检查 | 结果与边界 |
|---|---|
| 最终 FR255 发布构建 | 成功，PRG 10,367,628 B；散列、源码提交及编译警告数写入安装包 `build-info.json` |
| Monkey C 回归 | 56 PASS，0 failed，0 errors；覆盖记录/失败恢复、原生 FIT 调用、800 条历史、连续数组对齐、投影复用、缩放坐标、瓦片边界与加载失败等 |
| Python 地图生成 | 7 项全部通过，包括双级覆盖、唯一资源编号及下载失败保留原资源 |
| 正常应用事件压力 | 恢复两份旧 v1 合成摘要（800 条，含一个断段），由系统调用生产 MapView 的绘图与定时器；100 次混合操作后保存并正常退出，运行器返回 0 |
| 再次打开 | `ZOOM_REOPEN_PASS`、序号至少为 3、800 条与断段保留，随后 `ZOOM_STOP_PASS stage=1`；退出码未单独保留 |
| 图像资源异常 | 最终正常事件日志没有资源错误；错误分支通过单元测试注入，不代表实机图形池峰值已测 |

单元运行器依然在所有用例 PASS 后返回 1，这是本环境已存在的运行器异常；不能把该退出码写成 0。日志中的 `MAP_TILE_DRAW_FAILED` 来自故意注入的错误测试。正常应用压力程序使用独立应用 ID 与合成数据，未使用用户的原始轨迹、FIT 或错误日志。

100 次混合操作具体是 40 次缩放、40 次平移、20 次回中，另有切换操作模式的 START 按键。按键由测试控制器注入委托，生产视图不覆写 `onUpdate`，控制器在回调之间归还事件循环。定位只调用跟随策略检查“浏览不被拉回”，不是完整卫星事件重放；活动中 FIT 状态另由单元用例验证。

## 内存与性能观察

正常事件压力结束时普通堆采样为 **57,368 B**，100 次混合操作流程耗时 **47,437 ms**。后者包含控制器等待和底图准备，不能除以操作数当作实机按键延迟。图形池不包含在普通堆数值内，该采样也不是持续峰值。

单元测试中的完整地图绘制、历史恢复绘制、双槽模型存储采样分别为 102,136 B、102,368 B、124,808 B。20 帧平移绘制样本中，800 条密集/分散轨迹的中位数均为 31 ms；这些同步调用不包含正常定时器排队，且计时粒度较粗，不能据此宣称比旧版更流畅。

开发时，满容量历史配合底图切换出现长时间停顿，而相同流程在少量历史下正常；减少长期保留的小数组并取消每帧成对坐标分配后，最终满容量流程完整通过。证据支持保留本次内存布局调整，但未确定 SDK 内部图形池或垃圾回收的具体机制。

## 仍需手表验证

按照 [安装与复测说明](INSTALL-V04.md)，先保留旧历史测试打开、20 次双级切换、两级上下/左右平移、退出和重开，再进行短程记录测试。重点关注 IQ!、轨迹和底图错位、旧摘要丢失、圆屏文字可读性及长轨迹手感。

实机交互延迟、100 次交互、连续两小时稳定性、成对耗电、FIT 文件内容和 Garmin Connect 同步未在本轮完成。合成摘要中的 7200 秒字段只是测试数据，不代表已跑两小时。候选版不可称为稳定版。

安装包使用明确文件清单，包含源码来源、构建散列、地图元数据与测试日志，不含签名私钥、SDK、测试 PRG 或个人活动文件。远端 CI 结果由打包时的 `build-info.json` 记录；CI 只做 Python/语法/XML/清单检查，不能代替本地 FR255 构建或实机验收。
