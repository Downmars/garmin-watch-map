# v0.5.0-alpha.1 验证记录

- Windows x64 独立 EXE 启动并出现「离线地图制包器 · FR255」窗口。桌面界面测试使用实际画布点击，创建三个途经点，保存为 GPX，保存项目并重新打开，地区和路线数量一致。
- 用该 EXE 从新的工作目录实际调用 SDK 编译渭南和西安钟楼两个地区、三条合成路线。最终 ZIP 通过文件清单与 CRC 检查；发布 PRG 为 10,909,148 字节，SHA-256 为 f7be83741d17f5d686e819612c6fc2cb89eacfe4e65cfd62e665b9a973430ea7。
- Python 11 项通过，覆盖项目连同 GPX 移动到另一目录、越界拒绝且保留原输出、GPX 异常坐标、范围预算与断段简化等。
- FR255 模拟器 57 项逐项 PASS，0 failed、0 errors。新用例从正常菜单切换地区与路线、在真实绘图缓冲绘制、重建视图读取上次选择、切换同地区第二条路线和隐藏叠加，并检查已有轨迹未被改动。SDK 单元运行器在全 PASS 后仍返回 1。
- 本机使用 Connect IQ SDK 9.3.0、Java 17.0.20.1。桌面程序由 PyInstaller 6.16.0 打包。真实 FR255 上的安装、切换手感、长时间运行，以及另一台新电脑的首次设置仍待验证。
