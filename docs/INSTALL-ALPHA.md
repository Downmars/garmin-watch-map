# 渭南 FR255 · v0.2.0-alpha.2 安装与验收

这是待实机验证的候选版。原 v0.1 安装包可用来回退。本版没有 FIT 保存，退出后临时轨迹会丢失。

alpha.2 修复 alpha.1 静止罗盘更新时出现的 IQ!。两个版本的 PRG 大小相同，请从 **alpha.2 安装包**中取文件。新 PRG 的 SHA-256 为 `211a29830402e503c52cd926a37467116859722af1f8d0e0a833eb973c37b132`。

## 你需要操作的步骤

1. 解压版本安装包，找到其中的 `weinan-fr255.prg`。只把这个文件复制到手表。
2. USB 连接 FR255，打开 `此电脑 → Forerunner 255 → Internal Storage → GARMIN → Apps`。将原有同名 PRG 先复制到电脑备份，再用候选文件替换。文件大小应为 **9,314,140 字节**；不要把整个压缩包、测试 PRG 或调试文件复制到手表。
3. 等待传输完成，断开 USB，从手表应用列表打开「渭南地图」。如果手表已自动重命名旧应用文件且没有同名文件，不猜测或删除其他 PRG；先通过手表应用管理卸载旧「渭南地图」，再安装候选版。

若 Garmin 文件夹又出现空白/卡顿，先完成连接排障再复制，不新建替代系统目录。

## 新按键逻辑

| 操作 | 效果 |
|---|---|
| UP / DOWN | 沿当前轴平移地图，并进入浏览模式 |
| START | 切换上下 / 左右平移轴 |
| 浏览模式按 BACK | 回到最近接受的位置，恢复跟随；没有位置时回到渭南预设中心 |
| 跟随模式再按 BACK | 退出应用；临时轨迹不会保存 |

地图保持北向朝上。红色位置箭头代表当前有效定位；灰色圆圈代表历史位置。顶部会提示等待定位、GPS 正常、弱信号、定位过期或超出地图范围。

## 优先复测静置崩溃

室外等待「GPS 正常」，静置 3–5 分钟并缓慢转动表盘；随后步行、停下再观察。不应再出现 IQ!，方向应继续更新。如果仍有异常，保留最新日志并记录发生时间，以便与 alpha.1 的旧日志区分。

## 其余约 10 分钟检查

1. 室外等待「GPS 正常」，步行一段有转弯的安全路线，观察位置与方向。
2. 按 UP/DOWN 平移，等待 30 秒，应保持浏览；按 BACK 应回中。
3. 进入室内或遮挡处，观察弱信号/过期提示；回到室外后，失联前后轨迹应分成两段。
4. 记录版本、固件、是否出现 IQ!、按键是否流畅，以及异常的复现步骤。无需上传私人活动轨迹。

本次检查不用于证明续航提升或全部功能稳定；详细验收见 `VALIDATION.md`。

## 回退

退出地图应用，重新连接 USB，用保留的 v0.1 `weinan-fr255.prg` 替换候选文件；传输完成后断开。旧版 SHA-256 为 `13ba24ea67752266fdac079ada071337fde46e7e99d6bf362b976cdd59321eb2`。
