# 验证与实机验收

## 结果分级

- **编译通过**：只证明目标 SDK/设备配置接受源码与资源。
- **自动测试通过**：只覆盖明确列出的场景；使用模拟输入，不下载真实城市瓦片。
- **模拟器通过**：可以验证状态和交互，不能推出真实卫星质量、续航或设备稳定性。
- **实机通过**：记录手表型号/固件、版本、安装文件哈希、场景、结果。截图显示文件在 Apps 中不等于应用已经运行。

## 必测场景

| ID | 输入 / 操作 | 期望 |
|---|---|---|
| GPS-01 | 启动但无位置 | 显示等待定位；预设城市中心不显示成真实当前位置 |
| GPS-02 | 空坐标、质量为空或 LAST_KNOWN | 不更新可信位置，不增加距离 |
| GPS-03 | POOR → USABLE/GOOD | 弱信号提示；恢复后重新建立有效轨迹段 |
| GPS-04 | 有定位后回调中断超过 10 秒 | 下一秒刷新显示定位过期；旧位置去掉实时方向箭头 |
| GPS-05 | 持续回调但定位时间戳重复/回退 | 不把旧数据续期为新定位 |
| GPS-06 | 断信号后在远处恢复 | 不把失联前后两点连成运动距离或轨迹 |
| GPS-07 | 静止 5 分钟 / 100 米跳点 | 不因单次跳点增加里程；记录静止漂移，不能只用直线模拟宣称过滤准确 |
| MAP-01 | 定位越出四条边界 | 显示超出地图范围；不把真实位置夹在边界上 |
| MAP-02 | 进入浏览，持续收到 GPS 30 秒 | 保持浏览位置；主动回中后恢复跟随 |
| MAP-03 | 无定位时回中、连续切换轴 | 无异常，状态明确，所有操作可通过按键完成 |
| TRK-01 | 超过最大显示点数，多次回绕 | 内存有界，断段不被错误连接 |
| REC-01 | 开始、暂停、恢复、保存、丢弃、意外退出 | 对应 FIT 行为清楚，取消不丢已有记录；v0.3 才能标通过 |
| ZOOM-01 | 两地图级别同坐标切换 100 次 | 位置和比例尺一致，峰值内存达标；v0.4 才能标通过 |

## 用户执行的最短实机检查

1. 保留旧版 PRG；只复制明确标注的候选 PRG 到 `GARMIN/Apps`，传输完成后断线。
2. 记录 FR255 固件版本、候选版本、初始电量；室外开阔处等待定位。
3. 步行约 10 分钟，包含直线和两次转弯；观察位置、方向、距离和轨迹。
4. 在地图里平移后等待 30 秒，再主动回中；确认行为符合该版本说明。
5. 在安全位置进入室内或遮挡处，观察弱信号/过期提示；恢复室外信号后检查是否出现跨越失联区间的直线。
6. 退出并重新打开；按版本说明确认是否保留记录。alpha 如出现 IQ!，保留 `GARMIN/Apps/LOGS` 中与该应用相关的错误日志。

GPS 日志可能包含实际位置。公开 issue 只附必要的错误栈、版本与经过处理的测试数据，不默认上传原始活动或个人轨迹。
