# 离线地图制包器 · Windows x64

打开 FR255-Atlas-Studio.exe。示例项目含渭南主城区、西安钟楼和三条合成演示路线。

地图下方显示当前视野的接收速度、已接收大小、瓦片进度、缓存数与用时，生成安装包时下方另有整个离线包的下载统计。速度使用近 3 秒实际收到的图片字节计算，缓存命中单独计数。显示「等待服务器响应」或「等待重试」时速度可能为零，超过 3 秒无数据会降到零。进入「正在编译」后可通过状态区分地图下载与编译阶段。失败尝试可能产生已接收数据，累计大小记录实际网络接收量。

切换视野后会取消旧视野后续重试。正在等待的网络连接需返回或超时后释放工作线程，预览连接超时设为 10 秒。此时显示「等待下载队列」，接着显示「查找本地缓存」和请求状态。HOT 预览逐个尝试 a、b、c 入口，每个入口一次。

## v0.8 路线与地点编辑

主地图可滚轮缩放、左键拖动平移，也可点「查看全部」回到地区范围。地图只在当前视野加载瓦片，加载过程可继续编辑。放大后会请求更清楚的底图，最高 z19，实际级别取决于所选图源。

点「新建路线」开始绘制，选中路线后点「编辑所选」或双击路线进入编辑。窗口中切换「浏览」「画路线」「编辑节点」「地点」。右键拖动地图在各种模式下都可用。

- 画路线时逐点点击，当前分段内相邻点连线。「新分段」用于断开的线路。
- 编辑节点时拖动节点调整位置，点击线段附近插入节点，选中后可删除。Ctrl+Z 撤销、Ctrl+Y 重做，最多保留 50 步操作。
- 地点模式点击地图添加地点，拖动地点调整位置，在右侧修改名称、类别、备注与同步开关，点「应用属性」。左侧主窗口的「地点标注」可单独编辑地区地点。
- 「定位经纬度」接受 WGS84 的“纬度, 经度”。「手表配色与简化线预览」用于查看 16 色、制包简化线及圆形视野范围。
- 「导出 GPX」导出当前路线与地点。「应用到项目」将结果加入项目，含路线时会选择编辑副本的 GPX 保存位置，默认文件名带“编辑”。

编辑窗口关闭时保留草稿，下次打开相同地区与路线可选择恢复。项目修改后也会自动保存本机草稿，下次启动可恢复，随后用「保存项目」保存正式 JSON 和路线副本。

GPX 航点使用标准 `wpt`，名称、备注与类别随文件保存。即使 GPX 只有地点，也能导入项目或据此建立地区。编辑后的 GPX 用作规划路线，原活动文件中的逐点时间、海拔等记录信息请保留在原文件中。

每地区电脑端可编辑 256 个地点，最多选择 32 个同步到 FR255。手表备注使用前 160 字符，地图只展开所选地点的短名称。需要同步的地点和路线须在离线地区覆盖范围内，超出时调整地区或同步开关。

1. 点「添加」输入地区名称、WGS84 中心和边长。已有 GPX 时，点「从 GPX 建立地区」，软件会根据路线估算范围。点「载入预览底图」可在联网时查看覆盖区域。
2. 选中左侧地区，点「导入 GPX」加入一条或多条路线。也可以点「新建路线」，依次点选转弯位置，保存为 GPX 并加入该地区。手绘相邻点以直线相连。
3. 点「保存项目」，得到项目 JSON 和同目录的路线文件夹。把两者一起发送给其他制包者，就能继续编辑。
4. 点「生成手表安装包」并选择 ZIP 保存位置。把 ZIP 发给使用 FR255 的人；接收者解压，把其中的 weinan-fr255.prg 放到 GARMIN/Apps。地图菜单中选择「地图地区」或「GPX 路线」。

第一次制包，在「制包设置」选择 [Garmin Connect IQ SDK](https://developer.garmin.com/connect-iq/sdk/) 的目录和 Java 17 JDK 的 java.exe。用 SDK Manager 安装普通 Forerunner 255 设备配置。选择自己已有的 .der 签名，或点击「创建新签名」。保存私钥备份，以后更新自己的包时继续使用。Windows EXE 随附 Python、Pillow、界面和手表应用模板。Garmin SDK、设备配置和 JDK 由制包者一次性安装。只接收 PRG 的人只需要手表和 USB 数据线。

首轮下载需要网络，底图按地区缓存。框选范围为正方形，使用 WGS84 经纬度；非 WGS84 路线应先转换。项目可以包含 1–8 个地区、每个地区最多 16 条路线。制包器检查 GPX 是否越界，将路线简化到最多 192 个点，保留分段和端点，过于复杂时会提示拆分。FR255 候选包限制为 180 张合成底图和 15 MB PRG，防止误选过大范围。每个项目生成一个安装包，包内切换即时生效。加入新地区和路线后，再生成一次并同名覆盖。

路线蓝线用于查看预设路径，深红色轨迹记录实际移动。选中地区时进入浏览，选择路线时地图移到起点，BACK 回中。此次范围为导入、手绘和离线切换；剩余距离与偏航提醒属于后续导航功能。

手表主菜单用「开始记录」启动活动；「设置 → 活动类型」可选择步行、跑步、骑行或通用轨迹，选择会保存在手表上。活动类型不需要重新制包。

若提示 `Invalid device id specified: 'fr255'`，在「制包设置」中检查 **FR255 设备目录**。默认自动读取 Garmin SDK Manager 的下载位置。Windows 常见设备目录为 `%APPDATA%\Garmin\ConnectIQ\Devices\fr255`，应包含 `compiler.json` 与 `fr255.bin`。设备目录缺失时，在 SDK Manager 的 Devices 页安装普通 Forerunner 255。alpha.2 会先检查设备配置，并把选中的目录传给编译器。本版本使用 Garmin SDK 9.3.0 验证。

## 在线底图

点「在线底图」填写获准用于此应用的 HTTPS XYZ 栅格瓦片模板和手表上的署名，保存项目并重新生成 ZIP。模板应按 WGS84 经纬度使用 Web Mercator、256×256 像素瓦片、Y 向南递增，提供 z13 和 z15，各含一个 `{z}`、`{x}`、`{y}`。例如 `https://tiles.example.invalid/{z}/{x}/{y}.png` 仅演示格式。地址会写入项目和生成的 PRG，仅使用允许公开的客户端令牌。请求只包含当前可视瓦片坐标，采用 Garmin 图片接口，该接口不提供自定义请求头。图源须允许这种访问及署名方式。

旧项目或留空地址只用离线地图。配置图源后，在线图片经手机 Garmin Connect 按需取得，离线图片先显示。每次只发起一个有效请求，最多保留视口中心附近四张在线图片。请求等待 15 秒后放弃，失败后间隔 30 秒再试。超出当前地区时会寻找包内其他覆盖该位置的底图。网络状态切换不改变视口、GPX 选择或运动记录。测试时可先在已打包地区观察「在线」，再断开蓝牙观察「离线」，最后恢复蓝牙。实机表现受图源与手机网络影响。

## 从源码运行

安装 Python 3.11+（带 tkinter）、Pillow。在仓库目录执行：

```powershell
python -m pip install Pillow
python tools/atlas_studio.py
```

生成桌面 EXE：

```powershell
python -m pip install pyinstaller==6.16.0
python tools/freeze_studio.py
```

自动化制包可以用 `python -X utf8 tools/atlas.py examples/atlas.json --check` 检查项目，再指定 `--sdk`、`--java`、`--key`、`--output`。UTF-8 模式可在英文版 Windows 重定向日志时正确输出中文地区名。项目使用稳定的地区/路线 id 和相对 GPX 路径，格式见 examples/atlas.json。底图生成、GPX 解析和桌面界面分别使用同一套制包逻辑。底图和编译在临时目录完成，校验全部通过后才替换输出 ZIP。个人 GPX 会成为计划路线的一部分，只把成品分享给预期的接收者。

底图、数据许可与手表安装步骤见 [安装说明](INSTALL-V05.md)。
## v0.7 统一地图图源

点击「地图图源」，选择 MapTiler 街道、MapTiler 户外或自定义 XYZ。MapTiler 填访问密钥，自定义图源填写 HTTPS 模板、样式名称、简短署名和完整许可。可分别设置是否启用手机在线请求和是否已确认离线授权。

新图源共用预览、离线制包和手表在线请求，使用同一套 16 色调色板。坐标需为 WGS84，投影为 Web Mercator，瓦片为 XYZ 256px 图片，提供 z13/z15。高德 GCJ-02、百度 BD-09、TMS、PBF 和 512px 图片需要相应适配，当前会在配置或图片校验时拒绝。

离线制包会预下载所选区域。MapTiler API 批量下载需要 Custom 方案或相应授权，勾选前先核实账户权限。说明见 [MapTiler 官方离线文档](https://docs.maptiler.com/guides/using-map/atak-maps/)。完整署名写入安装 ZIP 的 `MAP-LICENSE.txt`，手表显示简短署名。项目文件及手表安装包中可能包含在线访问密钥，分享前使用专用、可撤销的访问密钥。

旧项目打开后保留原 HOT 离线与独立在线地址。选择「保留旧项目配置」可继续编辑旧地址，切换到新图源并保存后，三处统一使用新配置。每个项目当前选择一个图源，更换后重新制包。

预览下方显示底图资源数量、待下载数量及未压缩总量估算。安装文件的大小取决于地图内容和 Garmin 编译器的压缩，以编译后的 PRG 实测为准，超过 15 MB 会停止并保留旧 ZIP。底图总量估算不代表手表同时占用的内存。

缓存按图源和样式隔离，切换图源后不会显示另一厂家的旧瓦片。新图源缓存位于设置的缓存目录下 `sources-v1/<指纹>/z/x/y.png`，旧 HOT 缓存保持原位置。

MapTiler 预设面向具备离线授权的使用方案。免费方案还要求展示品牌 Logo，使用不同方案或图源时按其要求核对。署名规则见 [MapTiler 官方说明](https://docs.maptiler.com/guides/map-design/attribution/add-attribution/)。
