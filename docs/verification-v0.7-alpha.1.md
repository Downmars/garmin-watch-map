# v0.7.0-alpha.1 验证记录

验证环境为 Windows x64、Python 3.12、Pillow、Java 17、Garmin SDK 9.3.0 和完整普通 fr255 设备配置。

## 完成的检查

- 22 项 Python 测试通过，覆盖原有 15 项和 7 项图源回归。新用例检查旧项目重开、预设与坐标规格拒绝、跨样式和旧缓存隔离、错误图片与错误请求的密钥隐藏、预览与制包共用像素和调色板、署名与包内元数据、授权失败时保留旧包、资源和缓存数量检查。
- MapTiler Streets v4 和 Outdoor v4 接口各请求一张渭南 z13 瓦片，均返回 256×256 PNG。此检查验证接口和图片规格，离线批量授权仍需使用者核对。
- 统一图源测试使用自制合成瓦片。应用及含 72 项 Monkey C 测试的 PRG 编译成功。此测试不依赖外部图源批量下载。
- 最终 PyInstaller EXE 分别重建当前保存的旧项目与统一图源合成项目。两包均检查 ZIP CRC、版本、地区和路线内容、在线配置、图源元数据、许可文件、PRG SHA-256 和 15 MB 上限。
- 当前保存项目为 2 地区、3 路线，沿用原 HOT 离线和已保存的在线配置。PRG 约 10.9 MB，具体字节数和最终校验值见交付目录的 `build-info.json` 及包内 `atlas.json`。
- 统一图源合成项目的非测试 PRG 约 7.1 MB。合成图片的压缩率不能代表真实城市或户外地图的安装体积。

## 验证限制

- 72 项 Monkey C 测试已编译，模拟器运行器仍在启动阶段超时且未输出结果。分别检查了连接探测、工作目录及默认设备路径，临时配置和目录映射均已恢复。运行测试尚未完成。
- 尝试打开模拟器时用户按 Esc，已停止电脑界面操作。新图源窗口的可视验收尚未完成。
- 长轨迹、在线图片与离线地图组合时的实际堆/图形内存、长时间续航，以及街道/户外地图在 FR255 上的可读性仍待真机验证。现有 4 张在线缓存、单个网络请求、100 KiB 空闲堆门槛和两级缩放保持原有约束。
- 体积预估显示未压缩底图数据总量和资源数，PRG 使用编译后的实际体积检查。未将未经校准的 PNG 大小换算成确定的 PRG 预测。
- v0.6.0-alpha.4 保留为阶段性验收和回退版本。

## 图源接入范围

本版提供 MapTiler 街道/户外预设，以及 WGS84、EPSG:3857、XYZ、256px 的自定义 HTTPS 图片源。在线、预览和离线采用同一个地址与样式。支持的图源需提供 z13 和 z15，并满足离线使用及分发要求。

参考 [MapTiler 图片 API](https://docs.maptiler.com/cloud/api/maps/)、[MapTiler 户外地图](https://www.maptiler.com/maps/outdoor/)、[MapTiler 离线使用](https://docs.maptiler.com/guides/using-map/atak-maps/)。
