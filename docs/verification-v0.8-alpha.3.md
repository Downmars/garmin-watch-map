# v0.8.0-alpha.3 下载显示与等待修复

主预览、路线编辑器和离线制包显示接收速度、累计接收大小、瓦片进度、缓存数、用时和失败尝试。速度以近 3 秒的图片响应数据计算，缓存读取单独计数。下载、等待响应、重试、本地缓存读取、地图处理和编译分别显示状态。

切换视野时会取消旧视野的后续重试。已发起的网络连接需要返回或超时后释放工作线程。预览请求连接超时为 10 秒，HOT 逐个尝试 a、b、c，每个入口一次。正在排队时显示「等待下载队列」。

39 项 Python 检查通过，新增用例覆盖分块接收、无数据时速度归零、缓存计数与重复计数、两套图源实际字节统计、失败重试、取消旧请求，以及正常安装包流程中的统计传递和编译状态。

2026 年 11 月 11 日本机连接测试使用同一组渭南 z16 瓦片坐标。HOT 的三个入口均在约 9 秒超时，另一已配置图源在约 2.75 秒返回 HTTP 200、256×256 PNG，共 9,477 字节。此次结果表明本机能够取得另一图源的图片，HOT 的访问路径仍有超时。服务响应会随网络和时段变化。

速度统计记录下载响应的实际字节，包括失败尝试已收到的部分数据。TLS、连接等待、服务器响应延迟、重试等待和图片处理会影响总用时。

冻结 EXE、云端构建和界面检查结果随交付文件记录在 build-info.json。
