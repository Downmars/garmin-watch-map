# v0.2.0-alpha.1 验证报告

日期：2026-11-06；对象：普通 Forerunner 255 的渭南离线地图。

**后续发现：alpha.1 在实机静止罗盘更新时会触发 `Symbol Not Found: abs`，不再推荐安装。修复与同场景前后对比见 [alpha.2 验证报告](verification-v0.2-alpha.2.md)。原始结果保留如下。**

SDK 返回码异常的初步排查：本地 SDK `MonkeyDoDeux` 根据日志正则匹配设置通过标志，其匹配字符串与本次日志格式存在差异。保留原始返回码和完整日志，不修改 SDK，也不无条件吞掉失败码。当前发布依据是编译成功和逐项测试日志，仍标记为 alpha。

## 当前限制与下一步

- 定位只接受 USABLE/GOOD；以接收计时器判断过期，同时拒绝已见过的时间戳。尚不以绝对系统时间验证首个定位的年龄；源时间戳缺失时只能使用质量与接收时间。
- 旧的 50 米单段过滤和 8 米屏幕轨迹抽稀仍在；静止漂移、连续跳点和高速运动场景留待后续测量与改进。
- 浏览模式 BACK 回中，跟随模式 BACK 退出。没有保存菜单，退出仍会丢失临时轨迹；不是完整运动记录器。
- 本版未增加缩放、比例尺、GPX 路线、FIT 保存或轨迹恢复。
- 请执行 [VALIDATION.md](VALIDATION.md) 的首轮实机检查；完成前不合并为稳定发布。
