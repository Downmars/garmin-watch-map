# 渭南 FR255 · v0.4.0-alpha.1

本候选版增加街道/概览两级地图和比例尺，保留 v0.3 的 FIT 记录、历史轨迹恢复与启动修复。完整实机验收尚未完成。

## 安装

先保存并退出正在记录的运动，再连接 USB，将本包 `weinan-fr255.prg` 覆盖到 `Internal Storage/GARMIN/Apps`。保持同名，等待传输完成再断开。只复制 PRG，不复制测试程序或调试文件；不卸载应用，不删除 DATA/SETTINGS，已有 v1 轨迹摘要继续兼容。

## 缩放与浏览

| 地图顶部模式 | UP / DOWN | START |
|---|---|---|
| 上下 | 上移 / 下移 | 切到左右 |
| 左右 | 左移 / 右移 | 切到缩放 |
| 缩放 | 放大到街道 / 缩小到概览 | 切回上下 |

初次进入为街道图、上下模式。按两次 START 到“缩放”，按 DOWN 看概览，再按 UP 回街道。两级之间视野约相差 4 倍，比例尺同步变化；达到边界后保持该级别，不循环跳转。当前级别显示为“街道”或“概览”。

缩放保持当前地图中心。手动平移后进入“浏览”，GPS 更新不会把视角拉回；按 BACK 回中恢复跟随。在跟随状态再按 BACK 打开运动菜单。模式切换、平移和缩放不暂停 FIT。菜单仍为 UP/DOWN 选择、START 确认、BACK 返回。

切换后新底图分次载入，可能短暂显示灰底和“载入底图”；若显示“底图暂不可用”，可切换级别或移动到另一片区域重试。全城覆盖范围没有扩大；边缘之外留灰底。这里的概览是较小比例的底图，不能保证一次显示整条长轨迹。

## 首轮复测

1. 先保留旧历史轨迹直接打开，不开始新运动。满轨迹恢复仍会先显示“正在恢复轨迹”，完成后应看到原有轨迹。
2. 切换街道/概览 20 次；观察同一地理点是否保持居中，轨迹是否随底图一起缩放，是否出现 IQ!。
3. 两个级别分别切到上下、左右模式，连续平移各 10 次。观察长轨迹是否导致越来越慢，浏览时是否被定位拉回。
4. BACK 回中，再 BACK 进入菜单，选择“退出地图”；重新打开，检查历史仍在、没有 IQ!。
5. 上述通过后再进行短程步行，记录中尝试缩放、暂停、继续和保存。开始新运动会清空旧屏幕轨迹；FIT 保存与同步检查沿用 [v0.3 说明](INSTALL-V03.md)。

反馈启动、缩放、平移、退出重开是否正常即可。若出现 IQ!，保留最新 CIQ_LOG.YML，不清空轨迹恢复数据。

## 本版范围与回退

- 最多保留最近 800 条屏幕记录（包括断段标记）。没有按日期选择多次活动、自动显示整条轨迹的入口、目的地搜索或自动寻路。
- “查看最近轨迹”和地图信息页留待下一阶段。实机手感、长时间内存、两小时耗电与 Garmin Connect 内容仍待验证。
- 回退时先结束运动，再用原 v0.3.0-alpha.3 的同名 PRG 覆盖。不回退到存在启动超时问题的 v0.3 alpha.1/alpha.2。
