# v0.6.0-alpha.4 本地验证 — 2026-11-10

用户于 2026-11-10 反馈本版功能暂时正常，并授权上传 GitHub。本记录描述本地验证结果，云端构建结果见对应提交的 GitHub Actions。

## 变更

- 主菜单只有一个「开始记录」入口；在「设置 → 活动类型」选择步行、跑步、骑行或通用轨迹，并以稳定标识存储上次选择。初始默认步行，记录中不允许更换当前会话类型。
- 手表屏幕轨迹改为结合定位间隔和速度判断跳点，避免正常骑行、开车因相邻定位点超过 50 米被误断。所有活动类型使用相同判断，Garmin 原生 FIT 记录接口不变。
- 弱定位、超过 10 秒间隔、时钟异常、暂停恢复和明显跳点仍会断段；不会补齐已有历史断线。

- 用户反馈「功能暂时看起来正常」，未提供各项测试的单独记录。此反馈作为阶段性功能验收。
- 15 项 Python 离线回归测试通过。首次运行受到临时目录写入权限影响；改用工程内的临时目录后全部通过。
- Garmin SDK 9.3.0、Java 17、完整 fr255 设备配置：应用及包含 72 项测试的 PRG 编译成功。

- 最终桌面 EXE 成功重建用户保存的项目。验证安装 ZIP 的 CRC、地区/路线内容一致性与 PRG SHA-256；具体地区数量、在线配置及最终文件校验值以交付目录的 `build-info.json` 和包内 `atlas.json` 为准。

- 分享 ZIP 只包含制包器、说明、许可与公共示例；不含签名私钥、SDK/JDK、用户地图包或私人 GPX。

## 尚未完成

- 模拟器测试运行器在启动后 180 秒内没有输出测试结果，超时退出。**72 项仅编译通过，不能视为运行通过。** 临时修改的模拟器设备目录配置已恢复。
- 随后尝试检查模拟器窗口时，用户按 Esc 停止电脑操作；已停止 UI 操作。本版没有完成可视界面验证。
- 真机重启后活动类型持久化、骑行/乘车连续性、FIT 分类、长时间内存与耗电仍待分别记录。阶段性功能反馈的覆盖范围未逐项确认。

## 建议验收

1. 结束当前活动，按安装说明覆盖同名 PRG。进入「设置 → 活动类型」选骑行，退出再打开，确认仍选中骑行。
2. 室外 GPS 正常后用唯一的「开始记录」启动；暂停、继续、保存，确认 Connect 中活动分类正确。
3. 骑行或乘车时记录一段与之前类似的路线，结束后查看红线连续性。弱信号或长时间无定位时仍允许断段，勿将真实缺失点连成假轨迹。
4. 安装包继承制包时保存项目的在线图源配置；图源有效性与真实手机蓝牙传图需要在连接手机后另行检查。更换在线图源时，用新版制包器打开项目重新制包。
