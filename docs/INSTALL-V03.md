# 渭南 FR255 · v0.3.0-alpha.3

本版修复长轨迹恢复时打开即 IQ!，保留平移优化。alpha.1/alpha.2 存在长轨迹恢复超时风险，停止推荐安装；新版本为实机待复测候选版。

## 安装

退出地图并结束手表上其他正在进行的运动。USB 连接后，将本包的 `weinan-fr255.prg` 覆盖到 `Internal Storage/GARMIN/Apps`，等待传输完成再断开。无需复制测试包、调试文件或其他文件夹。版本和校验值见 `build-info.json`。

## 按键

| 场景 | UP / DOWN | START | BACK |
|---|---|---|---|
| 地图 | 沿当前轴平移 | 切换上下/左右轴 | 浏览时先回中；跟随时打开运动菜单 |
| 运动菜单 | 选择项目 | 确认所选项目 | 返回地图 |

## 记录一次步行或跑步

1. 室外等待「GPS 正常」。按 BACK 打开菜单，选择「开始新步行」或「开始新跑步」，按 START。开始新活动会清空上次屏幕轨迹。
2. 地图下方显示「记录中」及累计运动时间。需要休息时，BACK →「暂停运动」→ START。暂停时地图定位继续更新，屏幕轨迹、里程和运动计时停止累计。
3. BACK →「继续运动」恢复同一 FIT 会话；暂停前后屏幕轨迹分段显示。
4. 结束时选择「保存运动」或「保存并退出」。看到「FIT已保存」才表示 Garmin 保存接口返回成功；如果显示失败，可在菜单重试。
5. 正常与手机 Garmin Connect 同步，检查本次活动是否出现，以及路线、运动类型、时长是否正确。本项目尚未完成这一步实机验收。

「丢弃运动…」会再次确认，默认选中取消。只有选择「确认丢弃运动」才会丢弃当前 FIT 并清空屏幕恢复轨迹；取消或 BACK 不丢弃。已保存的活动不会被这个菜单删除。

## 退出与恢复

- 没有未处理运动时，菜单提供「退出地图」。有未处理运动时提供「保存并退出」；保存失败则保留会话供重试。
- 正常由系统结束应用时，会尝试保存未处理 FIT；强制重启、断电或崩溃不能保证执行退出回调。
- 最近的简化轨迹和摘要约每分钟按需保存，并在暂停、保存、退出时立即保存。重开后显示「历史轨迹」，不会冒充实时位置，也不会继续上次 FIT 会话。
- 恢复摘要最多保留 800 个条目（含断段标记），完整活动依赖 FIT。恢复不等于恢复完整历史或接续中断的 FIT。
- 屏幕距离使用本应用的估算规则，可能与 FIT 的设备统计不同。当前不承诺心率、训练负荷等原生运动的全部指标。

## 首轮实机验收（约 10 分钟）

1. 开始新步行，走约 2 分钟；暂停后再走约 30 秒，确认屏幕距离/计时不增加。
2. 继续运动再走一段，确认没有跨越暂停区间连线；保存并退出。
3. 重开地图，确认显示历史轨迹；同步 Garmin Connect，检查是否出现正确活动。
4. 另开一次短测试，先进入丢弃确认再取消，确认仍可继续；随后确认丢弃，退出重开后不应恢复这次丢弃的轨迹。

出现 IQ! 时保留最新 CIQ_LOG.YML。反馈只需描述结果；无需公开上传私人轨迹。

## alpha.3 启动与长轨迹复测（约 2 分钟）

1. 若仍能进入旧版，先保存并退出当前运动；若打开即 IQ!，直接连接 USB 覆盖同名 PRG。不卸载应用，不删除 DATA 或 SETTINGS。摘要格式仍兼容 alpha.1/alpha.2，已有轨迹可用于复测。
2. 打开时会短暂显示“正在恢复轨迹 / 请稍候”。满容量两份摘要的模拟器恢复约 8 秒，实机可能不同；完成后再开始定位。恢复中 BACK 可退出，不写入半条轨迹。
3. 进入地图后确认历史轨迹正常。在同一片地图上连续平移 20～30 次；按 START 切换方向再试，观察是否仍越按越慢或出现长时间停顿。
4. 从菜单退出再打开一次，检查没有 IQ!、轨迹仍在；确认暂停处没有异常连线。不要为了测试先开始新活动，否则会清空这份历史屏幕轨迹。
5. 下次记录较长运动后再重复保存、重开和平移，反馈是否顺畅及是否出现 IQ!。若仍崩溃，保留最新 CIQ_LOG.YML；不要清空恢复数据。

## 回退与许可

需要应急恢复基础地图时，可先结束运动，再退回 v0.2.0-alpha.2；该版不会读取 v0.3 摘要，也没有 FIT 记录菜单。不要为规避此次长轨迹启动问题退回 alpha.1/alpha.2，它们使用相同的同步恢复路径。
